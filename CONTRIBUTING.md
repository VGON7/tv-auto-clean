# Contributing

Thanks for helping improve 电视自动清理.

## Before opening an issue

Please include:

- TV brand/model
- Android version
- 32-bit or 64-bit
- Whether the app is installed via U disk or ADB
- Steps to reproduce
- Relevant screenshots (remove personal info)

## Pull requests

- Keep the app dependency-free where possible (no AndroidX unless necessary).
- Preserve Android 5.0 (API 21) compatibility.
- Do not add `INTERNET` or analytics.
- Do not commit keystores, passwords, APKs, build outputs, or local SDK paths.
- Test on at least one Android TV emulator or device if possible.
- Update README/CHANGELOG for user-visible changes.
